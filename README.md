# LMSGI - AEA1: HTML i CSS

Aquest repositori conté les activitats pràctiques corresponents al mòdul **M0373 - Llenguatges de marques i sistemes de gestió d'informació (AEA1)** del cicle de Desenvolupament d'Aplicacions Web (DAW).

El projecte està dissenyat per ser desplegat directament a **GitHub Pages**.

---

## 📑 Contingut de les Activitats

### 02. Edició i format de text
- **Activitat 1:** Ús d'etiquetes de text, subíndexs (`<sub>`), superíndexs (`<sup>`), estil de codi i alineació vertical per a fórmules i esquemes.
- **Activitat 2:** Aplicació d'estils de text a paràgrafs i ressaltat de paraules clau sobre la temàtica de curiositats de Mart.

### 03. Llistes
- **Activitat 1:** Llistes no ordenades amb elements personalitzats mitjançant icones de fons (`background-image`).
- **Activitat 2:** Llistes ordenades utilitzant estructures amb seccions i numeració personalitzada (elements no continus i format de números romans).

### 05. Enllaços
- **Activitat 1 (Navegació interna):** Pàgina d'una sola secció amb menú d'enllaços interns (`#id`), blocs alternats amb la pseudoclasse `:nth-child` i botó de retorn a l'inici.
- **Activitat 2 (Navegació multipàgina):** Estructura de pàgines independents per a les pel·lícules de la saga Spider-Man, amb un menú de navegació que gestiona l'estat de la pàgina activa.

---

## 🚀 Desplegament i Manteniment

El lloc web utilitza rutes relatives per garantir una navegació fluida tant en entorn local com en **GitHub Pages**. 

Per afegir noves activitats en el futur, només cal incloure els nous fitxers a la secció corresponent i afegir el seu enllaç a la llista del fitxer principal `index.html`.
